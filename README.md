# ELVARIANS_data

Public data outputs for ELVARIANS supporter systems.

This repository is intended to host generated public JSON files through GitHub Pages.

Private supporter source files, platform IDs, Discord IDs, raw VRChat display names, event logs, notes, secrets, and peppers must not be committed here.

## Public paths

```text
docs/supporters/v1/manifest.json
docs/supporters/v1/supporters.runtime.json
docs/supporters/v1/supporters.board.json
docs/supporters/v1/supporter.styles.json
docs/supporters/v1/notices.json
```

Expected GitHub Pages base URL:

```text
https://elva-vrc.github.io/ELVARIANS_data/
```
