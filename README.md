# remote-static

Public static runtime data outputs.

This repository is intended to host generated public JSON files through GitHub Pages.

Private source files, platform IDs, Discord IDs, raw display names, event logs, notes, secrets, and peppers must not be committed here.

## Public paths

```text
docs/data/v1/manifest.json
docs/data/v1/supporters.board.json
docs/data/v1/supporter.styles.json
docs/data/v1/notices.json
```

Expected GitHub Pages base URL:

```text
https://elva-vrc.github.io/remote-static/
```
